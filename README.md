# Python Fundamentals Notebook

Repositorio personal de estudio dedicado a los fundamentos de Python mediante notebooks interactivos y documentación práctica.

Los materiales incluyen ejemplos de código, ejercicios y explicaciones sobre conceptos básicos e intermedios del lenguaje. El objetivo es centralizar notas de aprendizaje y facilitar su consulta y experimentación.

## Contenido

La carpeta `notebooks` contiene apuntes organizados por temas. Estos recursos sirven para:

- Repasar conceptos fundamentales de Python.
- Consultar ejemplos prácticos.
- Ejecutar y modificar el código en tiempo real.
- Experimentar con estructuras de datos, funciones y control de errores.
- Practicar técnicas habituales de programación.

## Requisitos

Necesitas tener instalado:

- Python 3
- Jupyter Notebook o JupyterLab

También puede utilizarse una distribución compatible con Jupyter, como Anaconda.
